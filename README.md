# Archives Unification — Women Religious Collections

**A standardized framework for assessing, reconciling, normalizing, and integrating collections from multiple women religious repositories into a unified archival environment.**

This project establishes scalable methodologies for:
- archival arrangement and description
- metadata normalization and reconciliation
- ArchivesSpace and EAD ingest workflows
- authority and controlled vocabulary management
- quality assurance and validation
- preservation of community context and provenance
- long-term stewardship and public access

**Core Standards:** DACS · EAD · Dublin Core · PREMIS  
**Primary Systems:** ArchivesSpace · Omeka S · Preservation Repositories

# Purpose

This project documents a repeatable and evidence-based framework for standardizing, reconciling, and integrating collections from approximately ten legacy repositories into a centralized archival environment while preserving provenance, community context, and discoverability.

The framework is designed specifically for distributed women religious archival environments where:
- collections have evolved across multiple custodians
- descriptive practices vary significantly
- metadata structures are inconsistent
- physical and intellectual arrangements have diverged over time

The project emphasizes reciprocal archival processing rather than unilateral standardization.

# Process Overview

## 1. Discovery and Assessment
- inventory incoming systems and materials
- assess descriptive quality and risk
- identify processing history and structural inconsistencies
- preserve original informational environments before transformation

## 2. Consolidation and Preservation
- merge legacy datasets into unified environments
- preserve source provenance
- preserve original labels, identifiers, and terminology
- capture physical arrangement evidence

## 3. Structural Normalization
- identify invalid spreadsheet structures
- normalize record-level relationships
- convert flattened data into hierarchical archival structures
- reconcile duplicated or conflicting fields

## 4. Arrangement and Description
- apply standardized series and subseries models

- construct reciprocal relationships between legacy and normalized systems

## 5. Metadata Crosswalks and Reconciliation
- normalize authorities and controlled vocabularies

- generate ArchivesSpace import structures
- create EAD-ready hierarchical environments
- attach digital objects and preservation metadata

## 7. Quality Assurance and Validation
- validate required fields and structural integrity
- verify identifiers and URIs
- conduct sampling and reconciliation checks
- document remediation decisions

## 8. Publication and Access
- publish to public discovery systems
- validate derivatives and links
- implement access restrictions and rights statements

## 9. Sustainability and Iterative Processing
- support long-term stewardship
- maintain documentation and training
- permit iterative normalization and reconciliation
- preserve reciprocal links between systems

# Linear Reciprocity Model and Reciprocal Ingest

The Linear Reciprocity Model (LRM) provides the theoretical and operational framework for this project.

Rather than treating archival ingest as a one-directional migration into centralized systems, the model views ingest as a reciprocal negotiation between:

- originating informational cultures
- legacy organizational systems
- physical arrangement environments
- archival standards
- archival information systems
- archivists and users interacting with collections

This framework recognizes that:
- normalization should not erase originating informational structures
- legacy systems contain embedded contextual meaning
- reciprocal mappings preserve long-term interpretive value
- archival systems should adapt to collections before collections adapt to systems

The OLVM ingest process operationalized these principles in practice.
