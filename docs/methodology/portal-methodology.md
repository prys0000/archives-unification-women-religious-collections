# NAPWR Portal Methodology

## Purpose

The NAPWR Portal for the Archives of Women Religious is designed as a **federated discovery layer**, not a replacement repository.

Participating institutions remain the authoritative custodians of their records. NAPWR provides shared discovery across those independently maintained archival environments.

## Methodological Model

The portal uses **provenance-aware schema mediation**.

Source repositories are treated as historically situated information systems rather than deficient versions of a single future database.

The portal therefore standardizes only the elements needed for reliable exchange and discovery while preserving:

- source attribution
- authoritative record links
- congregation identity
- local terminology where meaningful
- legacy identifiers
- descriptive distinctions
- repository context

## Five Core Operations

### 1. Source-System Characterization

Document:

- source platform
- hierarchy
- identifiers
- date practices
- authority practices
- digital-object relationships
- local terminology
- access URLs
- known data-loss risks

### 2. Canonical Exchange Modeling

Map selected fields into a shared NAPWR structure.

The canonical model is an **interoperability contract**, not a replacement finding aid.

### 3. Reciprocal Transformation

Maintain:

```text
SOURCE RECORD ⇄ NORMALIZED PORTAL RECORD
```

Every derivative should remain attributable to its authoritative source.

### 4. Validation and Exception Capture

Check:

- hierarchy
- required fields
- identifiers
- dates
- authority values
- media URLs
- rights
- repository values
- collection relationships
- source links

### 5. Iterative Rule Formalization

Recurring exceptions become:

- crosswalk updates
- parsing rules
- validation tests
- authority mappings
- training documentation

## Architectural Principle

**Custodial decentralization + discovery standardization**

The portal should allow a researcher to begin with a person, place, congregation, ministry, subject, or date rather than requiring prior knowledge of which repository holds the evidence.

## Researcher-Centered Discovery

The portal supports complementary access paths:

- collection search
- faceted browsing
- congregation browsing
- contributing-hub browsing
- Sisters Name Index
- digital-object access
- AI-assisted conversational discovery

## Epistemic Boundary

NAPWR must distinguish:

- source evidence
- normalized metadata
- system-generated relationships
- AI-generated explanatory language

These are not epistemically equivalent.

The source archival record remains authoritative.
