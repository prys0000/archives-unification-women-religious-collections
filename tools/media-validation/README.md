# Media Validation Toolset

## Function

Validates digital-object relationships and public access derivatives.

## Checks

- URL syntax
- allowed host
- primary file vs. thumbnail
- duplicate media
- missing media
- record/media mismatch
- identifier mismatch
- inaccessible link
- unexpected content type

## Audit Fields

- archival_identifier
- source_record_url
- media_url
- derivative_url
- host
- media_type
- validation_status
- warning
- checked_date

## Principle

Media is part of archival context, not decoration. A public image or PDF must remain correctly associated with the archival record that describes it.
