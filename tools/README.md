# Tool Documentation

These directories document the operational tool families used in the project.

The repository distinguishes **documentation of tool behavior** from **production scripts** so that methods remain understandable even when code versions change.

Tool families:

- EAD-to-Omeka
- ArchivesSpace import preparation
- spreadsheet normalization
- media validation
- authority reconciliation

Production code should include a version number or release tag that can be cited in congregation case records and audit outputs.
